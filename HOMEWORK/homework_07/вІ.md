2.2. Клиент хочет поставить звуковую карту в слот **PCIe x16 (electrical x4)**. Физически она влезет? Электрически будет работать? На какой скорости? Объясните правило «больше — можно, меньше — нельзя».
Влезет. Звуковая карта физически влезет в слот PCIe x16 (electrical x4), потому что он длиннее и совместим с меньшими картами. Электрически она тоже будет работать - PCIe поддерживает обратную совместимость.

Карта задействует только одну линию (x1) и заработает на скорости PCIe 3.0 x1.

Этой пропускной способности достаточно для аудио. Действует правило: меньшее устройство можно ставить в больший слот, но не наоборот.

«Больше - можно»: маленькую карту (например, x1) можно вставить в большой слот (x16). Она будет работать на своей скорости, лишние линии не нужны.

«Меньше - нельзя»: большую карту (например, видеокарту x16) нельзя вставить в маленький слот (х4) - не подойдёт по форме (ключи не совпадут) и не хватит скорости.

2.3. Если клиент установит второй NVMe SSD в слот M.2, который подключён к чипсету, а одновременно будет активно работать сеть 2.5G и USB 3.2 — какое ограничение возникнет? Назовите канал, через который чипсет общается с CPU, и объясните, почему возможен «бутылочный горлышко».
При одновременной работе второго NVMe SSD, сети 2.5G и USB 3.2 возникнет «бутылочное горлышко» на уровне чипсета.

Чипсет связывается с CPU через шину DMI 4.0 — она по скорости равна PCIe 4.0 x8 и даёт пропускную способность примерно 16 ГБ/с в обе стороны.

«Бутылочное горлышко» возникает, потому что все устройства на чипсете (второй NVMe SSD, сеть 2.5G, USB 3.2) делят эту одну общую шину.

В итоге устройства начинают конкурировать за полосу пропускания, и их реальная скорость падает.

Последствия: снизятся скорости копирования на SSD, реальная скорость сети будет ниже 2.5 Гбит/с, замедлится работа USB-устройств.

### Задание 3. Питание и VRM (темы: PS_ON#, PWR_OK, VRM, EPS, ATX 24-pin)

3.1. Опишите по шагам, что произойдёт с питанием платы после нажатия кнопки Power, если блок питания исправен, но **сигнал PWR_OK не поднимается** (неисправность БП). До какого этапа дойдёт система и почему?
1. Нажатие Power -> замыкается PWR_SW -> Super I/O фиксирует
2. Super I/O даёт PS_ON#  -> БП запускается, выдаёт +3.3V, +5V, +12V, -12V, +5VSB
3. Плата ждёт PWR_OK — подтверждение, что напряжения стабильны
4. PWR_OK не поднимается -> плата удерживает CPU в сбросе 
5. Процессор не стартует, POST не начинается, изображения нет

**Система дойдёт только до этапа «питание подано, CPU в сбросе»** — дальше не пойдёт, потому что без PWR_OK нет разрешения на старт CPU.
3.2. В выбранном наборе VRM имеет 12+1 фаз. Объясните, зачем нужно такое количество фаз для процессора с TDP 125 Вт / turbo 181 Вт. Что произойдёт, если поставить этот CPU на плату с VRM 6+1 фаз (как в варианте C)?
При 181 Вт turbo ток Vcore большой (~140 А при 1.3 В). 12+1 фаз делят ток — на каждую фазу нагрузка меньше: ниже температура дросселей, меньше пульсаций, стабильнее напряжение. Это даёт длительное удержание буста без троттлинга.<br>

Для 6+1 фаз (вариант C): ток на каждую фазу вдвое выше -> перегрев VRM -> срабатывание тепловой защиты ->v троттлинг CPU, а также риск нестабильности и деградации. 6+1 фаз для 181 Вт не хватает.


3.3. Блок питания имеет **один EPS 8-pin**. Материнская плата выбранного набора имеет разъёмы **EPS 8-pin + EPS 4-pin**. Можно ли подключить только 8-pin? К каким последствиям это приведёт при турбо-режиме CPU? Обоснуйте с точки зрения мощности и нагрева.
*Можно подключить только 8-pin*:
Cистема запустится.  EPS 8-pin держит ~235 Вт, чего в большинстве случаев хватает под 181 Вт turbo.
**При турбо:**
1. Весь ток CPU идёт через один 8-pin -> нагрев разъёма и кабеля
2. Возможны просадки напряжения и ограничение турбо 
EPS 4-pin даёт ещё ~150 Вт запаса и без него турбо может быть нестабильным, особенно при разгоне. По току и нагреву один 8-pin имеет меньший запас и хуже отводит тепло, чем 8+4.

3.4. Объясните разницу между **ATX 24-pin** и **EPS 8-pin** по назначению и напряжениям. Почему нельзя запитать CPU от 24-pin напрямую?
| | ATX 24-pin | EPS 8-pin |
|---|---|---|
| Назначение | Основное питание платы (чипсет, память, PCIe, периферия) | Дополнительное питание CPU |
| Напряжения | +3.3V, +5V, +12V, −12V, +5VSB, а также сигналы PS_ON# и PWR_OK | Только +12V |
| Ток | Ограничен тонкими проводами и небольшим числом контактов +12V | Выделенные линии +12V с большим током (до ~20 А) |

**Почему питание CPU не подаётся через 24-pin:**
- контакты +12V в 24-pin не рассчитаны на ток CPU (до ~20 А) — это ведёт к перегреву и просадкам;
- CPU требует **отдельных выделенных линий +12V** с увеличенным сечением;
- EPS 8-pin предназначен специально для питания CPU, тогда как 24-pin для этой задачи не предусмотрен.

### Задание 4. Память и профили (темы: DIMM, XMP/EXPO, тренировка DDR, чипсеты)

4.1. В выбранном наборе RAM — DDR5-6000 CL30 с профилем EXPO/XMP. Объясните, что произойдёт при первом включении, если профиль **не активирован** вручную. На какой частоте и с какими таймингами заработает память? Почему?
Если не активировать EXPO/XMP:

Без активации профиля память стартует в режиме JEDEC — это безопасный и гарантированно совместимый стандарт.

Частота: 4800 МТ/с (базовая для DDR5).

Тайминги: примерно CL40 (точное значение берётся из таблицы JEDEC для модуля).

Почему так: плата по умолчанию не применяет высокочастотные настройки, чтобы система запустилась на любой совместимой связке «CPU + плата + память». Итог: заявленные 6000 МТ/с и CL30 не заработают, пока пользователь вручную не включит EXPO/XMP в BIOS.


4.2. Клиент хочет добавить ещё 2 модуля RAM (итого 4×16 ГБ). Какие ограничения возникнут:
- по количеству слотов DIMM;
- по поддержке частоты (почему 4 модуля часто работают медленнее, чем 2);
- по контроллеру памяти CPU (IMC).

Слоты DIMM: нельзя поставить больше модулей, чем есть разъёмов; также надо сверить с макс. объёмом, который поддерживает плата.

Частота и стабильность: 4 модуля дают повышенную электрическую нагрузку - система может снизить частоту (особенно на DDR5) для стабильной работы.

Контроллер памяти CPU (IMC): у IMC есть предел нагрузки; при 4 модулях выше риск нестабильности на высоких частотах — может потребоваться ручная настройка таймингов или снижение частоты.

4.3. Можно ли в выбранную плату (DDR5) установить модуль DDR4 из старого ПК? Объясните с точки зрения ключа DIMM и электрической несовместимости.


Модуль DDR4 нельзя установить в плату под DDR5.

Физически это исключено из-за разного положения ключа (выемки) на модуле и в слоте DIMM: они не совпадают, и планка не вставляется.

Электрически стандарты несовместимы: DDR4 работает при 1,2 В без встроенного контроллера питания, а DDR5 рассчитана на 1,1 В и имеет на плате микросхему РМИС.

Контроллер памяти процессора и подсистема платы под DDR5 не поддерживают протокол и адресацию DDR4. Попытка установки может привести к повреждению оборудования.


4.4. Опишите, что делает UEFI при «тренировке DDR» и почему при неудаче EXPO система может откатиться на JEDEC-стандарт. Какая частота будет у DDR5 по JEDEC?
При включении EXPO прошивка UEFI проводит «тренировку памяти»: калибрует сигналы, подбирает тайминги и проверяет стабильность работы модулей.

Если тренировка не удаётся (из-за несовместимости, нестабильности сигналов или ограничений контроллера памяти), система откатывается на базовый JEDEC-стандарт.

Это гарантирует, что компьютер запустится и будет работать стабильно даже при неоптимальных настройках памяти.

Частота DDR5 по JEDEC: 4800 MT/c (типичные тайминги — около CL40).

### Задание 5. Smart-настройки без входа в BIOS (темы: Smart Fan, Zero RPM, PBO, Curve Optimizer, Adaptive Voltage, BIOS Flashback)

*Все ответы — на основе логики работы технологий, без реального запуска.*

5.1. Клиент жалуется, что в простое ПК шумный. Какие **две** smart-технологии из изученных нужно задействовать, чтобы устранить шум, не снижая производительность под нагрузкой? Опишите, как каждая из них работает и какие пороги/кривые вы бы предложили.
**1. Smart Fan** Плата считывает температуру CPU/VRM и запускает вентилятор по кривой «температура -> обороты».
Кривая: `40°C -> 25%`, `60°C -> 50%`, `75°C -> 80%`, `85°C -> 100%`.
 В простое — низкие обороты, под нагрузкой — максимум.
**2. Zero RPM** Ниже порога вентилятор полностью останавливается
Порог: **50–55 градусов** для CPU_FAN и SYS_FAN.

5.2. Для выбранного набора (AMD или Intel — зависит от вашего выбора в задании 1) опишите, как **PBO + Curve Optimizer** (для AMD) или 

**Ожидаемый эффект:**
- температура в играх: **−8…−12°C** (например, 85 → 73°C);
- частоты: **не падают**, буст держится дольше — **+100…200 МГц** в длительной нагрузке;
- шум кулера снижается.

**Adaptive Voltage + Undervolting** (для Intel) повлияют на температуру и частоты. Приведите ожидаемый эффект в градусах и мегагерцах (ориентировочно).
**Adaptive Voltage + Undervolting:** фиксированный Vcore заменяется offset-смещением −0.05…−0.08 В. В простое напряжение падает до ~0.85 В, под нагрузкой — ровно необходимое.

5.3. Клиент купил новый процессор, который **не поддерживается текущей версией BIOS** платы. Плата не стартует. Опишите, как с помощью **BIOS Flashback** прошить плату без CPU и без входа в BIOS. Какие файлы и действия нужны?

5.4. Объясните, почему **Zero RPM** не конфликтует с **Smart Fan**: как плата решает, когда полностью остановить вентилятор, а когда начать раскручивать. Что произойдёт, если порог Zero RPM поставить выше критической температуры VRM?
*Как это работает на плате:*

Они не противоречат друг другу: Zero RPM — «выключения ниже порога», Smart Fan — «как крутить выше порога».
Если порог Zero RPM завышен относительно критической температуры VRM:
VRM остаётся без обдува, пока температура не достигнет завышенного порога -> троттлинг и риск деградации или отказа VRM. Порог Zero RPM должен быть ниже критических температур VRM/CPU.
